# Fada Feliz

Jogo de plataforma 2D no estilo Sonic: uma fada corre pelo jardim, coleta flores, bate as asas e lança encantos nos insetos espinhosos até chegar ao portal.

Textos da interface em português do Brasil. Os visuais são desenhados no canvas (sem assets pagos).

## Controles

| Tecla | Ação |
| --- | --- |
| ← → | Correr. Segure para ganhar velocidade; ao soltar, a fada ainda desliza um pouco. |
| ↑ | Bater as asas. Cada toque dá um impulso; toque várias vezes para subir ou planar. As asas cansam no ar (5 batidas) e o fôlego volta ao aterrissar. |
| Espaço | Lançar um encanto (projétil) que derrota os insetos espinhosos. |
| P ou Esc | Pausar ou continuar. |
| Enter | Começar, continuar ou jogar de novo. |

No celular ou tablet, use os botões na tela (esquerda/direita, magia e voar).

## Objetivo

Colete flores, evite (ou derrote) os insetos e alcance o portal florido no fim do jardim. Você tem 3 vidas. Cair no buraco ou encostar em um inseto custa uma vida; ao perder todas, é possível recomeçar.
